gllvmTMB fits multivariate models for data where each site, individual, species, or study has several responses. The first question is usually not mathematical:

Which responses vary together, and how much variation is shared rather than response-specific?

This page does one small, reproducible example. It loads a prepared morphometrics object, fits the model from a wide trait table first, checks the equivalent long-data call, and extracts the covariance, correlation, communality, and ordination summaries a reader normally wants first.

gllvmTMB has an experimental lifecycle: the formula grammar, defaults, and reported summaries and intervals may still change as the API matures.

The online guide follows the development branch and may describe features absent from this 0.7.1 release. Use this installed vignette and package help for the matching release syntax. The linked online Current limitations and boundaries page is supplementary and may include changes made after 0.7.1. For the scope and restrictions of 0.7.1, use this release’s NEWS and the help and vignettes installed with the package. The Gaussian latent model below is retained as a teaching example for the covariance decomposition and rotation-invariant summaries. Use this fit to learn the decomposition and interpret covariance point estimates. For a first point estimate in the narrow tested Gaussian setting, start with indep() or dep() and check fit health. The example does not certify general interval coverage.

The fitted Gaussian model starts with observations, not with the covariance matrix. For each individual and trait, the teaching model is:

\[ \begin{aligned} y_{it} &= \alpha_t + \boldsymbol{\lambda}_t^{\mathsf T}\mathbf{u}_i + e_{it},\\ \mathbf{u}_i &\sim \mathcal{N}(\mathbf{0}, \mathbf{I}_d),\\ e_{it} &\sim \mathcal{N}(0, \psi_t). \end{aligned} \]

Here \(y_{it}\) is the observed value for individual \(i\) and trait \(t\). The intercept \(\alpha_t\) is the average for trait \(t\). The vector \(\mathbf{u}_i\) is the individual’s latent score: where that individual sits on the unobserved trait axes. The row vector \(\boldsymbol{\lambda}_t\) says how strongly trait \(t\) responds to those axes. The leftover term \(e_{it}\) is the part of trait \(t\) not shared with the other traits.

In generalized models, \(\eta_{it}\) is the linear predictor and the link function \(g()\) connects it to the mean response: \(g(\mu_{it}) = \eta_{it}\). This first example uses a Gaussian family with the identity link, so the linear predictor is the mean itself.

The R formula for that model is compact:

fit <- gllvmTMB(
  traits(length, mass, wing, tarsus, bill) ~ 1 +
    latent(1 | individual, d = 2),
  data = df_wide,
  unit = "individual",
  family = gaussian()
)

After fitting, the covariance among traits is the first report-ready summary implied by the latent part of the model:

\[ \begin{aligned} \operatorname{Cov}(\mathbf{y}_i) &= \boldsymbol{\Sigma},\\ \boldsymbol{\Sigma} &= \boldsymbol{\Lambda}\boldsymbol{\Lambda}^{\mathsf T} + \boldsymbol{\Psi},\\ \boldsymbol{\Psi} &= \operatorname{diag}(\psi_1,\ldots,\psi_T). \end{aligned} \]

In words: total trait covariance = shared multivariate structure + response-specific variation. Lambda collects the trait loadings: one row per trait and one column per latent variable. The product Lambda Lambda^T is the shared covariance created by those axes. Psi is the diagonal matrix of trait-specific variance left over after the shared axes. Ordinary latent() estimates both pieces by default.

For a first fit, read Sigma, correlations, and communality before reading individual Lambda entries. The latent variables can be flipped or turned without changing the covariance they imply, so raw loading columns need a rotation or confirmatory constraint before they become a biological story.

First fit: wide individual-by-trait morphology

We have n individuals, each measured once on T morphological traits. The biological question: do the traits covary on a small number of latent variables (e.g. a body-size axis, a shape axis)? With one observation per individual-trait pair, ordinary latent() estimates both the shared low-rank component and the trait-specific diagonal Psi. No spatial or phylogenetic structure here.

library(gllvmTMB)

For a first fit, load the prepared morphometrics example object. It contains long data, wide data, and the truth table. The reproducible generator is data-raw/examples/make-morphometrics-example.R, but beginners do not need to read the generator before fitting the model.

The example has shared low-rank covariance \(\boldsymbol\Lambda\boldsymbol\Lambda^\top\) plus per-trait diagonal variance \(\boldsymbol\Psi\). The fit below recovers the individual-level covariance via ordinary latent().

In wide data, the formula term is latent(1 | individual, d = 2). In long data, the equivalent term is latent(0 + trait | individual, d = 2). The 1 in the wide form is the compact shorthand for the same trait-specific columns used in the long form.

Fit a d = 2 reduced-rank GLLVM with ordinary latent() at the individual level: the shared low-rank structure plus trait-specific unique variance, which ordinary latent() carries by default:

fit <- gllvmTMB(
  traits(length, mass, wing, tarsus, bill) ~ 1 +
    latent(1 | individual, d = 2),
  data = df_wide,
  unit = "individual",
  family = gaussian()
)

# A finite likelihood confirms that the model fitted; diagnostics come next.
as.numeric(logLik(fit))
#> [1] -739.6107

Same model, long data

If your workflow already stores one row per (individual, trait) observation, use the same entry point with the long formula and explicit trait = argument. Internally the wide formula pivots to this stacked form, so the two calls fit the same model; the log-likelihoods agree:

fit_long <- gllvmTMB(
  value ~ 0 + trait + latent(0 + trait | individual, d = 2),
  data = df,
  trait = "trait",
  unit = "individual",
  family = gaussian()
)

# Same fit:
all.equal(as.numeric(logLik(fit)), as.numeric(logLik(fit_long)))
#> [1] TRUE

What if some response cells are missing?

Wide trait tables do not need to be perfectly rectangular. If an individual is missing one trait measurement, leave that response cell as NA; gllvmTMB() can treat only that unit-trait cell as missing and keep the other observed traits for the individual. The same rule applies to long data with NA in the response column. Missing predictors and missing grouping variables are a separate problem: by default they fail loudly because the model cannot construct that row.

Each individual-trait cell has one observation, and the fitted diagonal Psi term is indexed at that same cell resolution. Exact conditional Gaussian residuals would therefore be almost zero and would make a misleadingly perfect Q-Q plot. )

The correlation results above are point estimates only. Profile intervals for correlations are unavailable. The separate total-variance route targets the diagonal of Sigma, not correlation. This example profiles one trait, chosen from the simulated truth table, and prints the interval status with its bounds. With real data, choose the trait to profile from the scientific question and pass its index with trait_idx; the simulated truth is used here only to make this example’s choice reproducible.

profile_trait <- which.max(diag(truth$Sigma))
total_variance_ci <- profile_ci_total_variance(
  fit,
  tier = "unit",
  trait_idx = profile_trait
)
total_variance_ci[, c(
  "trait", "estimate", "lower", "upper", "interval_status"
)]
#>   trait estimate    lower    upper interval_status
#> 1  mass  1.32874 1.074532 1.677931      route-only

certified-0.94 means the fit falls inside one simulated Gaussian regime (unpenalised native-Laplace, n_units >= 150, d <= 2, and a two-sided 95% input). Its measured 0.9467 marginal coverage is a 0.94 floor, not nominal 95% coverage or a guarantee for an individual interval. route-only means the bounds were computed outside that measured regime. The installed help ?profile_ci_total_variance lists the exact target and status rules. These total-variance intervals do not apply to the correlations shown above.

Choose a covariance source and level

unit is the between-unit covariance grouping, called B in older output. unit_obs is the within-unit observation grouping, called W in older output; each unit_obs level must be nested within one unit. These groupings are different from covariance source families:

Component Keyword family What identifies it
Between-unit or within-unit covariance indep(), dep(), latent() Use unit or unit_obs as the grouping factor in the formula.
Animal relatedness animal_indep(), animal_dep(), animal_latent() A pedigree, A, or Ainv supplies relatedness for the animal IDs.
Phylogenetic relatedness phylo_indep(), phylo_dep(), phylo_latent() A tree or vcv matrix supplies relatedness on the cluster axis, usually species.
Spatial fields spatial_indep(), spatial_dep(), spatial_latent() A mesh built from the fitted locations supplies the spatial structure.
Known kernel kernel_indep(), kernel_dep(), kernel_latent() A supplied matrix K supplies relatedness or similarity.

The mode describes covariance among traits: indep() gives separate trait variances with no cross-trait covariance; dep() estimates an unstructured trait covariance; and latent(..., d = K) estimates a rank-K shared component. Ordinary latent() includes diagonal Psi by default. A source-specific *_latent() term is loadings-only by default; use unique = TRUE to add its source-specific diagonal Psi. The older ordinary pair latent(..., unique = FALSE) + unique(...) remains accepted for compatibility. Check the installed help for the selected keyword before combining covariance sources.

Then inspect loadings and scores

The recovered loadings are useful, but they are not the first interpretation target. Only \(\boldsymbol{\Lambda}\boldsymbol{\Lambda}^{\mathsf T}\) is identified directly from the data; raw loading columns can change sign or rotate.

Lambda_hat <- extract_loadings(fit, level = "unit")
rownames(Lambda_hat) <- paste0("trait_", seq_len(n_traits))
colnames(Lambda_hat) <- paste0("LV", seq_len(ncol(Lambda_hat)))
round(Lambda_hat, 3)
#>           LV1    LV2
#> trait_1 1.026  0.000
#> trait_2 1.104 -0.152
#> trait_3 0.844  0.458
#> trait_4 0.746  0.558
#> trait_5 0.652 -0.551

Do not over-interpret the signs of these unrotated loadings. Use them as a quick look at the latent variables, then use Sigma, correlations, and communality for report-ready interpretation unless you have chosen a rotation or confirmatory constraint.

Choose your next guide

The next step depends on the question, not on adding every available model component:

  • Interpret covariance: continue with Individual morphometrics for a fuller Gaussian worked example.
  • Check the fit: use Can I trust this fit? before relying on coefficients, covariance, or uncertainty.
  • Choose a specialised model: use the Articles chooser to select repeated behaviours, reaction norms, binary occurrence, multivariate spatial structure, phylogenetic covariance, missing data, rank selection, or a technical reference. The spatial-model guide shows mesh construction and equivalent long- and wide-format fits.

Family, grouping structure, covariance source, covariance mode, missingness, and latent rank answer different scientific questions. Add only the pieces the sampling design and estimand require.
